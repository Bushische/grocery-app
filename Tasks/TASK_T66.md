# T66 — JEV decision fallback for unstructured chat input (chat-LLM-ready seam)
- **Goal:** Messy messages ("grab stuff for pancakes") resolve to an action with calibrated confidence instead of a clarify reply — via TypeSafe JEV, behind an interface a standard chat LLM can implement later.
- **Inputs:** T65 (deterministic first incl. multi-split), JEV docs (Decisions API `POST /api/alpha/decisions`, model `typesafe/jev-1.13` pinned — NOT the `latest` alias, so tuned thresholds stay stable; `state` + typed `questions`; answers carry probabilities + `usage.cost`; plain HTTPS, no SDK).
- **Why JEV shapes the design (not a chat LLM):** JEV returns NO free-form text — only typed `choice`/`noul`/`score` answers. So it classifies the ACTION (`add|list|bought|unbuy|unknown` as one `choice` question, ~0.2 s, $0.042/M in / free out) while product NAMES still come from the T65 deterministic splitter. Full free-text extraction stays a future chat-LLM implementation of the same seam.
- **Outputs:** `apps/api/src/telegram/extract.ts` — `Extractor` interface (`extractAction(text) → {action, confidence}`, `extractItems(text) → items[]`) with `DeterministicExtractor` (T65 logic) and `JevExtractor` (fetch-injectable Decisions client, zod-validated answers); wiring: deterministic-unknown → JEV action choice → confidence ≥ threshold (default 0.6, env-tunable) applies with split items, below → clarify; any JEV failure/timeout → clarify (never 500/loop); config `EXTRACTION_BACKEND=deterministic|jev` (default deterministic), `OPENROUTER_API_KEY` (secret, never logged), `JEV_MODEL` (default `typesafe/jev-1.13`), timeout 5 s, input cap 2000 chars; unit + inject tests with stubbed HTTP (choice routing, low-confidence→clarify, invalid-shape→clarify, timeout→clarify, backend=deterministic makes zero external calls — test-pinned).
- **Definition of Done:** deterministic hits make zero external calls; stubbed-JEV unstructured message routes end to end; JEV outage degrades to clarify; no new deps, no RAM change (external HTTPS); full gate green. Explicitly out: chat-LLM extractor (next task if JEV disappoints — the seam is the deliverable).
- **Dependencies:** T65.
