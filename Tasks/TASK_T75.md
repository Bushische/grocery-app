# T75 — Category-grouped TO_BUY with group-aware drag-and-drop
- **Goal:** TO_BUY renders grouped by category; dragging across groups moves the whole group, dragging inside reorders within it. BOUGHT stays a flat freshly-bought-first list (explicitly out — see T83 for its presentation).
- **Inputs:** `reorderItems` full-permutation `POST …/items/reorder` (no contract change), `item-sections.tsx` (`reorderedIdsAfterDrag`), `smartAddItem` end-of-section append, category `sortOrder`.
- **Outputs:** Grouped TO_BUY rendering (groups ordered by first-item position, items by `sortOrder` — groups stay contiguous without touching category `sortOrder`); group-aware drop computation (client, pure + unit-tested): inside-group drop → reorder within the group run; cross-group drop → dragged item to top of its group + its whole group block above the target's group (`a-a2-a-a-b-b2-b-…`, b2 above a2 → `b2-b-b-a-a2-a-a-…`); server inserts new TO_BUY items at the end of their category run and un-bought returns likewise (shift followers in-transaction; newly bought keep top-of-section, T48); optimistic updates mirror the same computation.
- **Definition of Done:** Unit tests pin rule 1 (within-group), rule 2 (block move per the example, incl. no-op on same-group), rule 3 (insert positions with followers shifted); DnD e2e on touch (≡ handle, 150 ms/5 px) + mouse; BOUGHT untouched (no handles, recency order); full gate green.
- **Dependencies:** T74.
