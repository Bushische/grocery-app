# T75 — Category-grouped lists with group-aware drag-and-drop
- **Goal:** TO_BUY and BOUGHT render grouped by category; dragging across groups moves the whole group, dragging inside reorders within it.
- **Inputs:** `reorderItems` full-permutation `POST …/items/reorder` (no contract change), `item-sections.tsx` (`reorderedIdsAfterDrag`, bought rows currently `sortable={false}`), `smartAddItem` end-of-section append, `moveItem` top-of-bought (T48), category `sortOrder`.
- **Outputs:** Grouped rendering in both sections (groups ordered by first-item position, items by `sortOrder` — groups stay contiguous without touching category `sortOrder`); drag handles + group-aware drop computation in both sections (client, pure + unit-tested): inside-group drop → reorder within the group run; cross-group drop → dragged item to top of its group + its whole group block above the target's group (`a-a2-a-a-b-b2-b-…`, b2 above a2 → `b2-b-b-a-a2-a-a-…`); new TO_BUY items and un-bought returns insert at the end of their category run, newly bought items at the top of their category run (shift followers in-transaction); optimistic updates mirror the same computation.
- **Definition of Done:** Unit tests pin rule 1 (within-group, both sections), rule 2 (block move per the example, incl. no-op on same-group), rule 3 (insert positions with followers shifted: end-of-group for to-buy/unbuy, top-of-group for newly bought); DnD e2e on touch (≡ handle, 150 ms/5 px) + mouse per section; full gate green.
- **Dependencies:** T74.
